Total downloaded assets: about 3.1 MB. They load lazily: the HDR after start-up, the textures with the terrain.

## Not used
All 3D models are still built in code from primitives (original). I did not find or download model packs (Kenney, Quaternius, Sketchfab) in this pass, so no models, rigs or plant meshes from outside were added, and there is no glTF pipeline (gltf-transform, KTX2, LODs) because there are no glTF files. No offline cache (PWA) exists in this project.

## Not licensed for use (rules)
CC-BY-NC, CC-BY-ND, GPL-only art, unclear "free download" licences, rips from commercial games and anything with a trademark or agency logo.

## Home-screen icons

`public/icon-192.png`, `public/icon-512.png`: original art drawn in code (`tools/trailer/icons.mjs`): a Moon with a base dome, a star field and a sun glow. No outside images or fonts. Used by the web app manifest so the game can be added to a phone home screen and run full screen.

## Not in the repository

A commercial song was used for one private demo screening of the trailer only. It is not stored in the repository (git-ignored), not part of the deployed site, and must not be published. The trailer in the submission uses the original music generated by `tools/trailer/music.py` (see docs/CREDITS.md).

## Sounds, models, text

- **Sounds in the game:** none are files. Every sound is synthesised at runtime with WebAudio (`src/audio/sfx.ts`).
- **3D models and textures other than the two CC0 sets above:** none; everything is built in code from primitives, or drawn on canvases at runtime.
- **Fonts:** the system font stack only; nothing is downloaded.
- **Datasets:** NASA records bundled as JSON (see `docs/CREDITS.md`); they are archived, nothing is fetched while playing.
- **Trailer music:** generated by code (`tools/trailer/music.py` on the `trailer` branch); see `docs/CREDITS.md`.
