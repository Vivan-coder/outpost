# Free realistic assets — check licence on each page before download, log in CREDITS.md

## 3D models
- NASA 3D Resources (nasa3d.arc.nasa.gov, science.nasa.gov/3d-resources): habitat, rovers, landers. Public-domain style, but each entry has a credit line; some are non-NASA.
- NASA SVS Moon GLB models (svs.gsfc.nasa.gov/14959): globe only, use for title/trailer backdrop.
- Poly Haven models (CC0) and Kenney space kits (CC0) for props.
- No CC0 lunar base found: build habitat/solar/greenhouse from primitives + realistic PBR textures. Avoid paid CGTrader/Unity packs.

## Textures / sky (CC0)
- Poly Haven: moon_* regolith/rock textures (some may be locked; check live), plus rock/dirt/sand for Mars.
- ambientCG: metal, panels, concrete, dirt (CC0).
- Poly Haven HDRIs for lighting; stars skybox from NASA imagery or generated procedurally.

## Audio
- Kenney audio packs (CC0): UI clicks, alerts.
- Freesound: filter to CC0 only. Pixabay Music: ambient space loops (Pixabay licence; check each track). OpenGameArt CC0 ambient sci-fi.
- Avoid BBC SFX (non-commercial) and any CC-BY-NC.

## Rule
Download only files with a visible CC0/public-domain/clear-free licence. Record URL + author + licence in CREDITS.md the moment you download.
