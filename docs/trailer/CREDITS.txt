OUTPOST trailer: credits and disclosure

FOOTAGE
- Recorded from the Outpost game itself (our own code and original art made from primitives; textures and sky as listed in docs/ASSETS.md, all CC0).
- NASA data shown: DONKI space weather records (May 2024 event), RadLab ISS dose range, OSDR study titles, Apollo Lunar Surface Journal note. Sources and dates are in docs/CREDITS.md and on the badges in the footage. No NASA logos or images are used.

MUSIC
- Original instrumental, generated by code (tools/trailer/music.py, numpy; additive synthesis, no samples, no third-party music). The code was written with AI assistance (Claude Code, Anthropic) and directed and checked by the author.
- Fixed random seed: the same file is produced every time.

SOUND EFFECTS
- None added in the trailer (the music is the only audio). The game's own sounds are synthesised in code and are not recorded in the trailer.

OTHER ASSETS
- End card: drawn in HTML/CSS (system font), QR code generated locally with the "qrcode" npm package (MIT).
- Tools: ffmpeg (video/audio processing), Playwright (browser control, Apache-2.0), jsQR and pngjs (QR check, Apache-2.0 / MIT).

AI USE DISCLOSURE
- The trailer pipeline (director script, recorder, music generator, compose and check scripts) and the game were written with Claude Code (Anthropic). No AI-generated images, video or voice are used. Tick the AI-use disclosure on the submission form.
